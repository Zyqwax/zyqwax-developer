# Zyqwax Auth Next.js

Next.js App Router uygulamana Zyqwax Auth girişini birkaç route ile ekle.

## Başlamak için

1. [Başlarken](/docs/getting-started) sayfasındaki package kurulumunu yap.
2. OAuth client bilgilerini ve environment değişkenlerini ekle.
3. Login, callback, me ve logout route’larını oluştur.
4. [OAuth akışını](/docs/oauth-flow) gerçek provider ile test et.

## Package

```bash
pnpm add @zyqwax-auth/nextjs
```

`@zyqwax-auth/nextjs` Next.js App Router ve Node.js runtime içindir. State, PKCE, token exchange, userinfo ve encrypted HttpOnly session işlemlerini kendisi yönetir.
